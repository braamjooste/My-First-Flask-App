## The requirement

Add a Flask contact form at /contact with name, email and message fields. Validate
all inputs on the server, reject missing or whitespace-only fields and malformed
email addresses with HTTP 400, preserve invalid input, and show a separate
confirmation after success. Store nothing and send no email. The session sheet
additionally requires Flask plus the Python standard library only.

```text
Add a contact form to my existing Flask application. Generate the actual working Python and HTML code, not just instructions or a plan.

I am completing a beginner lab comparing code generated by different AI assistants. Keep the solution simple, readable and easy to run.

3. Any required dependencies and the exact commands to install them and run the application.

5. Manual test steps for an empty submission, whitespace-only fields, a malformed email and a valid submission.

Before presenting the final code, review it against every requirement and correct any problems. If you can execute it, run the checks and report the results. If you cannot, clearly state that it has not been run.
```
